**☕ Coffee Shop Sales Analysis - Power BI Project**

This Power BI report explores and visualizes transactional sales data from a fictional chain of coffee shops. The purpose of this analysis is to uncover key sales trends, product performance, and the impact of marketing activities like campaigns and coupons.

## 📊 Key Insights & Features
- 📈 **Month-on-Month Growth**: Track sales performance trends over time.
- 🛍 **Product Analysis**: Identify high-performing product categories and types.
- 🏪 **Store Location Performance**: Compare sales across different store locations.
- 🎯 **Campaign Effectiveness**: Analyze the effect of special activities (e.g. coupons) on sales during specific months.
- 📦 **Order Quantity Patterns**: Study purchasing behavior and order sizes.
- 📉 **Statistical Summary**: Use of measures like mean, median, standard deviation to understand data distribution.

## 🛠 Tools & Technologies Used
- **Power BI**: Data visualization and dashboarding
- **SQL (Snowflake)**: Data querying and transformation
- **Excel**: Initial data manipulation and storage
